# Perfume Sales Analysis

## Project Overview

This project is an end-to-end data analysis of a perfume business. It explores sales performance, product profitability, customer behaviour and purchasing patterns using **Microsoft Excel, SQL, Python and Power BI**.

The goal is to transform raw sales data into meaningful business insights that can support better business decisions.

## Tools and Technologies

| Tool | Purpose |
|---|---|
| Microsoft Excel | Data cleaning, preparation and initial analysis |
| SQL | Data querying and business analysis |
| Python | Data analysis and visualisation |
| Power BI | Interactive dashboards and data visualisation |
| GitHub | Project documentation and version control |

## Project Workflow

1. **Data Cleaning:** Identified and handled missing values, duplicates and inconsistencies.
2. **Excel Analysis:** Calculated key performance indicators and explored sales patterns.
3. **SQL Analysis:** Used queries to investigate business performance.
4. **Python Analysis:** Performed further analysis and created visualisations.
5. **Power BI Dashboard:** Built three interactive report pages to communicate findings.

## Power BI Dashboard

The dashboard contains three interactive pages:

### 1. Sales Overview
Examines revenue, profit, total orders, sales channels and monthly sales trends.

### 2. Product Performance
Explores perfume profitability, revenue by fragrance type, quantity sold and customer ratings.

### 3. Customer & Sales Analysis
Examines customer types, payment methods, customer ratings and revenue by gender.
