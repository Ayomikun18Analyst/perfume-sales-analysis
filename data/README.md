 Data Files

This folder contains the datasets used for the Perfume Sales Analysis project.

 Files

- `Perfume_Sales_Raw.xlsx` – Original perfume sales dataset.
- `Perfume_Sales_Raw_Cleaned_Dataset.csv` – Cleaned dataset used for SQL, Python and Power BI analysis.

 Data Preparation

The dataset was reviewed and cleaned to address missing values, duplicate records and inconsistent entries before analysis.
